# Contributing

Thanks for your interest in contributing.

## Quick Guidelines
- Keep changes focused and well-documented.
- For notebooks, add a short summary in the relevant day folder.
- If you add new data, prefer small sample files and document the source.
- Run tests with `pytest` when applicable.

## Pull Requests
- Describe what changed and why.
- Link any related issues or notes.
- Include screenshots for visualization changes.
