# FAQ

## Who is this program for?
This program targets geoscientists, petroleum engineers, and subsurface professionals who want to build Python-first analytics workflows.

## Do I need advanced Python skills to start?
No. Comfort with basic Python and pandas is enough to begin. The first phase is designed to build fundamentals quickly.

## How much time should I plan per day?
Plan for 2-3 hours on weekdays. The cadence assumes steady practice rather than long weekend sprints.

## Can I skip days or rearrange the roadmap?
Yes. The roadmap is a guide, not a strict rule. If a topic is more relevant to your work, you can jump ahead.

## Where can I get help?
Use GitHub Issues for bugs and Discussions for questions or ideas. Links are in the README.

## Is the data real or synthetic?
The repo mixes open datasets and generated samples. Data folders include a short description for each dataset.

## How do I track progress?
Update the progress badge in `README.md` and the checklist in `docs/ROADMAP.md` after each milestone.
