# Support

Thanks for using the project! Here is the best way to get help.

## Questions or Ideas
- Use GitHub Discussions for help, ideas, and learning questions.

## Bugs
- Open a GitHub Issue with clear steps to reproduce, expected behavior, and your environment details.

## Contributions
- Read `docs/CONTRIBUTING.md` before opening a pull request.

## Response Times
This is a community-driven project, so responses may take a few days.
