# Security Policy

## Reporting a Vulnerability
If you discover a security issue, please do not open a public issue.

Instead, use GitHub Security Advisories for private reporting:
- Go to the repository's Security tab
- Select "Report a vulnerability"

If that is not available, open a GitHub Issue with minimal details and request a private channel.

## Supported Versions
This project is maintained on a best-effort basis. The `main` branch is the only supported version.
